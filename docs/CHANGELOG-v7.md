# 智农宝 · 农业数据全书 v7.0.0（四部分类 · 楷体排印 · part 分屏演示）

一款**番茄小说式**的 Qt 桌面阅读软件——把智农宝农业数据与茶文化数据组织成一部可翻阅的"数据之书"。

## v7.0.0 新增：把书分类、把字排好、把网页做成 part 分屏

- **四部分类**：七卷按主题归入 4 部 —— Ⅰ 国土与数据（卷一/五）、Ⅱ 作物与田畴（卷二/三）、Ⅲ 预测与决策（卷四）、Ⅳ 四十八年长卷（卷六/七）。书架按部展示，页眉标注部名。
- **字体规范**：全书中文正文 **楷体（KaiTi/STKaiti）**，数字、年份、拉丁字母 **Times New Roman**；QT 阅读器与内置网页同步。
- **关键词标注**：三类着色 —— 制度政策（红）、指标数据（蓝）、决断警示（金）；词典见 `content/typography.py`，QT 与网页共用同一份。
- **网页 part 分屏**：新增 `#/parts` 卷分类总目（3D 翻转卡片）+ `#/part/part1..4` 四个主题大屏（echarts 双轴图/柱形/饼图、数字翻牌、卷目导航、关键词标注故事区），参考「数据展示系统」压缩包的前端框架重做，带触摸反馈。
- **排印书稿**：`dist/智农宝农业数据全书_排印书稿_v7.0.0.docx` —— 楷体+TNR+关键词三色标注的 Word 全量书稿（含卷七 200 页、5 张 3D 插画）。
- **3D 立体插画**：新增 6 张等距 3D 插画（`app/assets/img3d/` 与 `app/site/assets/img3d/`）——智慧农田、数据立方、茶园、决策驾驶舱、改革时间轴、广东地图；书架英雄区、每章扉页、part 分屏横幅、Word 书稿均已嵌入。
- **数据图像扩充**：每个 part 分屏由 2 图扩到 **4 图**（主曲线 + 结构图 + 雷达多维画像 + 散点/桑基关系图），四个分屏共 16 张交互图表；网页 `#/parts` 总目 hero 也叠加了 3D 智慧农田背景。

## 一、它是什么

把原来散落在网页里的农业数据，重新编排成 **7 卷 35 章 / 卷七 200 页** 的连贯书籍，用真书阅读器的交互方式呈现。

### v6：把"翻页"做成真的
- **真书版式**：米色纸纹（程序合成）、装订侧阴影、内框线、页眉（栏目 + 卷名）、页脚（主题 / 页码 / 本章第几页）、页首大页码与下卷角。
- **10 章 × 20 页 = 200 页**：每页独立主题，卷七固定 20 页一章，页码连续可核对。
- **透视翻页动画**：旧页沿折痕卷起、露出新页，带折痕阴影与纸背亮边，320 ms 缓动。
- **翻页音效**：程序合成的纸张沙沙声（`turn / turn_back / open / close / tick`），顶栏 🔊 可一键静音。
- **四路翻页**：左右按钮、键盘 ←/→/空格/PgUp/PgDn、滚轮、点击页面左右两侧热区（悬停出现箭头）。
- **导航轨**：纸页右侧 20 个圆点，当前页高亮，点击直达任意页；底栏「跳到」页码框亦可。
- **书签**：一键写入当前章/页，进度与书签都存 `%APPDATA%\ZhinongbaoBook\progress.json`。
- **一页读完**：内容超高时自动按 4% 逐级缩排，200 页实测 0 页溢出。
- 目录抽屉显示每章页数与年份区间；夜间模式为深色纸面 + 浅色字。

## 二、决策 Agent（v4 新增）

阅读之外，软件内置一个**可嵌入大模型的决策 Agent**，首页书架与阅读页都有入口：

- **双引擎**：不配 API 时用本地规则引擎（查数/排名/预测/保本/市域/全书检索，全离线）；填任意 OpenAI 兼容接口（DeepSeek、通义、智谱、Kimi、OpenAI、本地 Ollama 均有预设）后，切换为 LLM + Function Calling 模式，由大模型自主调用上述工具。
- **工具可溯源**：每次回答下方显示「工具调用链」（如 `省级查询 · 保本测算`），数字全部来自本地真实数据，不是模型编的。
- **随问绘图**：涉及趋势与市域的问题会自动弹出图表窗口。
- **配置本地保存**：`%APPDATA%\ZhinongbaoBook\llm.json`，不上传；界面有「测试连接」按钮。
- **内置交互式网页版**：点「🌐 网页版」在本地 `127.0.0.1` 起服务并用默认浏览器打开——原来的 21 页分析网站（含图表、地图、预测、数字农田大屏）已完整封进 exe，可离线使用。

示例问句：`广东一产占比多少` / `2024年一产占比最高的5个省` / `深圳2018年GDP` / `农村居民收入未来3年趋势` / `水稻20亩、售价2.5元，保本吗` / `广东21市哪个最依赖农业`。

### 卷七每页的版式（20 页固定结构）
扉页（章题 + 引文 + 4 个数据锚点）→ 主题卡 → 正文若干页 → 数据页（真实序列图表）→ 档案页（政策文件摘录版式）→ 数据表 → 口述页（访谈引文）→ 方法页（可折叠的数据注记）→ 决策页（✅/🟡/❌ 三条决断）→ 尾页（下一章预告 + 留给读者的问题）。

### 卷七数据亮点（v5 新增）
- 官方长面板 **1978—2025**：农林牧渔业总产值、分行业产值、农村居民收入/消费/恩格尔/住房、粮食产量、GDP 与一产增加值，共 20 条序列。
- 农民收入 193.25 元（1978）→ 28,170 元（2025），**增长 145.8 倍**；总产值 85.94 亿 → 9,798.65 亿，**增长 114 倍**；恩格尔系数 61.7% → 36.6%。
- 2026 为复合增长率模型外推（收入 30,352 元 / 总产值 10,419 亿 / 粮食 1,330 万吨），**明确标注为演示级预测，非官方统计**。
- 网页版新增 `#/reform`「广东 1978—2026」决策页；决策 Agent 新增 `gd_reform_query` 工具（可查具体年份的官方值）。

## 四、数据真实性边界（务必阅读）

0. **官方权威数据（v5 新增）**：卷七 1978—2025 长面板逐格提取自《广东农村统计年鉴 2019》原表（总产值/分行业/收入/消费/恩格尔/住房/播种面积/作物产量），2019—2025 锚点来自广东省统计局统计公报与农业产值表；原始 PDF 存档在 `extra_data/gd_official/`，每条序列的来源 URL 写在 `guangdong_reform.json` 的 `meta.sources`。**2026 数值均为模型预测，不是官方统计。**
1. **真实数据**：31省面板（1980–2024）、宏观指标、作物播种面积来自本机比赛工作簿；黄瓜价格来自 GitHub `Asong205/price_yield_dataset`（Apache-2.0，公开样本 90 条）；茶文化内销量/额、出口额来自"数据展示系统"历史项目；**广东21市面板（1999–2018，420条）来自 GitCode `open-source-toolkit/db3cf` 开源的《中国城市统计年鉴》面板数据**；2024 广东省级农业数字来自广东省统计局统计公报。
2. **交互城市探索器**：卷五提供 21 市 × 7 指标下拉切换，实时重绘 20 年曲线（真实数据）。
3. **参考/推算数据**：crops.json 中 2022 年后的作物指标可能含增长率推算（原文件已标注）；预测与保本价页面的参数为内置参考值，仅作演示。
4. **未独立核验**：比赛工作簿数值未逐一对照国家统计局原表，广东市域面板的耕地面积字段在原始年鉴中大量缺测；引用请自行复核。
5. 所有数据**离线封装**在 exe 内，不联网、不上传。

## 五、运行与安装

- **直接运行**：双击 `dist/智农宝农业数据全书_v6.0.0.exe` 即打开书架，翻到卷七任意页即可体验翻页与音效。
- **安装到本机**（可选，创建桌面快捷方式）：`exe --install`
- **卸载**：`exe --uninstall`

## 六、从源码重建

```bash
pip install PySide6==6.8.2.1 pyinstaller
python build_book_data.py          # 从两个 zip 的解压目录重建 book_data.json 与图片
python build_guangdong.py          # 生成广东21市面板
python build_book_data_v31.py      # 追加卷五、卷六
python enrich_book_v4.py           # 给 25 章补充实证表与深读段落（幂等）
python build_gd_reform.py          # 从官方年鉴 PDF + 公报锚点生成 1978—2026 长面板
python build_reform_book.py        # 追加卷七 10 章主题内容（幂等）
python gen_media.py                # 合成翻页音效 + 纸张纹理（numpy 生成，无外部素材）
python build_reform_v6.py          # 卷七升级为 10 章 × 20 页（内容在 content/chNN.py）
python sync_site_v6.py             # 把 200 页目录同步进内置网页 #/reform
python test_reader.py              # 阅读器自检：翻页/热区/滚轮/书签/200 页排版扫描
python build_typeset_docx.py          # 生成楷体+TNR+关键词标注的排印书稿 .docx
python -m PyInstaller zhinongbao_book.spec --clean --noconfirm
```
