## 它解决什么问题

农业数据从来不缺，缺的是**从数据到动作的那一步**。

官方年鉴给的是"去年粮食产量多少"；而农户真正要回答的是"我今年这十亩地，种什么、卖多少才不亏、什么时候该收手"。这中间隔着一整套判断链：状态怎么感知、趋势怎么预测、决策怎么定、措施怎么落地、做完怎么复核。

智农宝把这套判断链**写成一本能翻的书**，并且让 Agent 能把它算出来。

| 层面 | 传统农业数据站 | 智农宝 |
|---|---|---|
| 形态 | 表格 + 图表页 | 8 卷 40 章 300 页真书，可翻阅 |
| 内容 | 罗列指标 | 指标 → 机制 → 决策 → 干预 → 复核 |
| 交互 | 点击筛选 | 透视翻页动画、纸张音效、书签、夜间模式、页码跳转 |
| 决策 | 无 | Agent 出保本价、风险等级、止损线、五段式处方 |
| 溯源 | 弱 | 每个数字标注来源与口径，外推一律标注"演示级" |

## 卷八：决策与算法精准干预

这是 v8 的核心。**每一章都遵守同一条纪律**：先定义状态 / 动作 / 收益 / 约束 → 再写算法输入输出 → 最后处方必须带触发条件与复核指标。不允许"想当然"。

| 章 | 主题 | 回答的问题 |
|---|---|---|
| 一 | 决策之问 | 为什么"有数据"不等于"能决策"？三个断层在哪 |
| 二 | 感知层 | 尺度怎么对齐？数据不够时系统为什么必须说"数据不足" |
| 三 | 预测层 | 三种增速算法怎么给出三个不同的故事？口径即结论 |
| 四 | 决策核心 | 保本价、四级风险、止损线、期望收益怎么算 |
| 五 | 干预闭环 | 处方怎么开、什么时候触发、做完拿什么复核 |

### 真实数据锚点

来自《广东农村统计年鉴 2019》逐页抽取 + 广东省统计局历年公报补齐：

| 指标 | 2015—2025 复合增长率 | 推出的干预结论 |
|---|---:|---|
| 农村居民人均可支配收入 | **7.745%** | 收入增长靠结构，不靠扩面 |
| 农林牧渔业总产值 | **6.331%** | 产值增速略低于收入，增值环节在产后 |
| 粮食产量 | **0.851%** | 粮食近乎零增长 → **增产不能靠扩面**，只能靠单产与品种 |

> 粮食 0.851% 这个数字是整个卷八的支点：它直接否决了"多种地就多赚钱"的直觉，把决策逼到"单产、品种、价格、成本"四个可操作变量上。

### 四类风险分级与对应动作

| 利润率 | 等级 | 系统建议动作 |
|---|---|---|
| ≥ 25% | 低风险 | 可小步扩种，锁 30% 订单 |
| 8% — 25% | 中风险 | 优先降本，暂不扩种 |
| 0% — 8% | 偏高风险 | 缩面积 20—30%，投保 |
| < 0% | 高风险 | 不建议种植，先止损 |

其中 `利润率 = 亩利润 / 亩收入 × 100%`，`止损线 = 保本价 × 105%`。

## 决策 Agent：从问答到行动

Agent 不是"问答机器人"，是**行动型**的：工具链串起来，最后落到一张能执行的处方。

```
用户："我种了10亩水稻，卖不上价，帮我做个决策方案"
   ↓
[cost_plan]       算保本价、利润率、风险等级
[price_trend]     查价格序列趋势
[gd_reform_query] 取官方增速锚点
[action_plan]      → 诊断 → 触发条件 → 决策 → 措施 → 预期 → 复核指标
   ↓
输出：五段式处方 + 完整工具调用链（哪一步用了哪个工具、拿到什么数）
```

支持两种模式：

- **离线规则引擎**（默认）：不联网、不花钱、不幻觉，纯本地数据 + 规则
- **大模型接入**：填入 `base_url` / `api_key` / `model` 即切换为 Function Calling；未填则自动回落离线

Agent 也可脱离 Qt 独立运行（Skill 包内）：

```bash
python scripts/agri_agent.py plan --crop 水稻 --area 10 --price 2.4 --problem 卖不上价
python scripts/agri_agent.py reform --metric rural_income --year 2026
```

## 快速开始

**直接用**：从 [Releases](../../releases) 下载 `智农宝农业数据全书_v8.0.0.exe`，双击运行，无需安装 Python。

**从源码跑**：

```bash
git clone https://github.com/lemonbaby2/zhinongbao-agri-data-book.git
cd zhinongbao-agri-data-book
pip install PySide6 python-docx matplotlib
python -m app.main
```

内置网页版（不启 Qt 也能看）：

```bash
cd app/site && python -m http.server 18423
```

浏览器打开 `http://127.0.0.1:18423/index.html`：
`#/parts` 卷分类总目 · `#/part/part1..4` 四个分屏 · `#/reform` 改革长卷

## 从源码重建

```bash
python build_gd_reform.py        # 解析年鉴 PDF → guangdong_reform.json
python build_reform_v6.py        # 生成卷七 10 章 × 20 页
python build_decision_v8.py      # 生成卷八 5 章 × 20 页（含真实数据注入）
python gen_decision_diagrams.py  # 生成 6 张数据图
python gen_media.py              # 合成纸纹与翻页音效
python sync_site_v8.py           # 同步到网页版
python build_typeset_docx.py     # 生成排印书稿 docx
python -m PyInstaller zhinongbao_book.spec --clean --noconfirm   # 打包 exe
```

> ⚠️ **打包必须用 `python -m PyInstaller`**。直接调 PATH 里的 `pyinstaller` 会走到另一套 Python 环境，漏打 PySide6，产出的 exe 会以异常小的体积启动失败。

### 验收

```bash
python test_reader.py   # 卷七 200 页布局回归
python test_v8.py       # 卷八 100 页渲染 + 溢出检查
python verify_exe.py    # exe 启动、窗口标题、资源完整性
```

| 元素 | 字体 | 说明 |

## 数据真实性边界

这一节请务必读完，它决定你能拿这个系统做什么。

| 数据 | 来源 | 可用性 |
|---|---|---|
| 广东 1978—2025 序列（20 项指标） | 《广东农村统计年鉴 2019》逐页抽取 + 省统计局历年公报补齐 | 可引用，需注明口径 |
| 2026 年数值 | 2015—2025 复合增长率外推 | **演示级，非官方统计**，不得作为生产计划或合同依据 |
| 31 省 1980—2024 面板 | 公开统计整理 | 可引用 |
| 广东 21 市 1999—2018 面板 | 中国城市统计年鉴 | 可引用 |
| 作物单产 / 售价 / 成本参数 | `CROP_REF` 演示值 | **必须替换**为当地品种、当季收购价、自家台账 |
| 对标系统成效（阿里农业大脑、丰登 SeedLLM、GEAIR） | 公开报道 | 属他人成果，**不是本系统的能力** |

口径纪律：

1. 2013 年起农民收入由"人均纯收入"改为"人均可支配收入"，序列已作衔接标注。
2. 恩格尔系数 2019 年后停止发布，后续消费结构改用八大类支出占比。
3. 价格高度本地化，本系统**不内置实时行情**，必须由使用者填入当地当季收购价。
4. 所有数据**离线封装**，不联网、不上传。
