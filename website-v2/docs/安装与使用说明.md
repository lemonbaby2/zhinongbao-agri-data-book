# 安装与使用说明（面向不写代码的使用者）

## 一、运行环境

- Windows 10 / 11（64 位）
- 默认浏览器：Edge / Chrome / 任意 Chromium 内核浏览器
- **不需要**安装 Python、Node.js、数据库或联网

程序只在本机回环地址 `127.0.0.1` 上起一个只读静态服务，用浏览器打开页面；不联外网、不上传数据、不需要账号。

## 二、安装

1. 双击 `智农宝_安装程序_v2.2.0.exe`。
2. 首次运行会弹出询问框：

   > 要把「智农宝」安装到本机吗？
   > 是：安装到 `C:\Users\<你的用户名>\AppData\Local\ZhiNongBao`，创建桌面快捷方式，可在「设置 → 应用」中卸载
   > 否：仅本次运行（便携模式，不改动系统）

3. 选 **是** → 出现"安装完成"提示 → 浏览器自动打开工作台。
4. 之后每次从 **桌面「智农宝」图标** 或 **开始菜单 → 智农宝** 进入。

安装做了什么（全部在当前用户权限内，不需要管理员）：

| 动作 | 位置 |
| --- | --- |
| 复制程序 | `%LOCALAPPDATA%\ZhiNongBao\智农宝.exe` |
| 桌面快捷方式 | 你的桌面（含 OneDrive 重定向的桌面也能正确识别） |
| 开始菜单快捷方式 | `%APPDATA%\Microsoft\Windows\Start Menu\Programs\智农宝.lnk` |
| 卸载登记 | `HKCU\Software\Microsoft\Windows\CurrentVersion\Uninstall\ZhiNongBao` |
| 运行日志 | `%LOCALAPPDATA%\ZhiNongBao\logs\app.log` |

## 三、日常使用

- **打开**：点桌面图标。如果程序已经在后台跑，不会重复启动，只会把浏览器再打开一次。
- **关闭**：直接关浏览器标签页即可。程序会在没人访问约 15 分钟后自动退出（页面上有"心跳"，标签页开着就不会退出）。
- **换端口**：`"智农宝.exe" --port 9000`（一般不需要）。
- **常驻不退出**：`"智农宝.exe" --idle 0`。

## 四、卸载

三种方式任选：

1. `设置 → 应用 → 已安装的应用 → 智农宝（农业数据工作台）→ 卸载`；
2. 开始菜单里右键「智农宝」→ 打开文件所在位置 → 运行 `智农宝.exe --uninstall`；
3. 命令行：`"%LOCALAPPDATA%\ZhiNongBao\智农宝.exe" --uninstall`。

卸载会删除：程序文件、桌面与开始菜单快捷方式、当前用户的卸载注册表项、运行日志。
不会删除：你另外保存的源码包、导出的 CSV。

## 五、常见问题

**1. 弹窗问"是否安装"时我选了否，还能再装吗？**
能。再双击一次 exe，选择"是"；或者直接运行 `智农宝_安装程序_v2.2.0.exe --install`。

**2. Windows 提示"已保护你的电脑 / 未知发布者"**
exe 没有代码签名证书，属于正常现象。点"更多信息 → 仍要运行"。若杀毒软件报毒，是 PyInstaller 打包程序的常见误报，可以把文件加入信任，或改用源码方式运行（见下）。

**3. 浏览器打开是空白页 / 一直转圈**
先看服务是否在跑：浏览器访问 `http://127.0.0.1:8765/__zn/health`，正常会返回
`{"app": "zhinongbao", "version": "2.2.0", ...}`。
若返回别的页面，说明 8765 被别的程序占用（例如上一次会话遗留的旧版服务器）——结束那个进程后重新打开即可；程序自身会自动改用 8766、8767…

**4. 想看日志**
`%LOCALAPPDATA%\ZhiNongBao\logs\app.log`，里面记录了启动、端口、每一次请求和卸载动作。

**5. 不想安装，也不想每次问**
把 exe 放到任意目录，用 `智农宝.exe --no-prompt` 启动即为纯便携模式。

**6. 机器上有 Python，想直接从源码跑**
双击包内 `start_dev.bat`，或命令行：

```bash
python desktop/zhinongbao.py
```

注意：源码方式需要 `site/` 与 `desktop/` 目录保持同级。

**7. 数据可以换成我自己的吗？**
可以。替换 `site/data/*.json`（字段结构保持一致）后运行 `python tools/build_core_data.py`，再重新启动即可；若要重新打包 exe，运行 `python tools/build_exe.py`。

## 六、数据边界（请务必知道）

- 页面里的数值来自本机比赛工作簿，**未**逐项与统计局原始发布核对；
- 作物指标 2022 年及以后可能是推算值，界面有色带和"可能含推算"标记；
- 「趋势预测」是浏览器内的最小二乘 / 指数外推演示算法，**不是**原项目的 SARIMA 模型，不能作为生产决策依据；
- 本应用不是 Manus 原站源码恢复版，原站已下线，前后端工程未在本机找到。
