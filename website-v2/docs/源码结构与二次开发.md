## 二、架构要点

### 1. 前端：无框架、无构建、可离线

- **hash 路由**（`#/data`）。好处是既能被本地服务托管，也能在 `file://` 下直接打开；旧的 `/data` 深链接会自动重写成 `#/data`。
- **数据层双层**：优先 `fetch('data/*.json')`，失败（`file://` 下浏览器禁止读同目录 JSON）时退回 `window.__ZN_CORE__`（`core-data.js`）。所以双击 `index.html` 也能看总览、对比、预测等页面；只有"工作簿逐表预览"需要 http 环境，页面会给出明确提示而不是空白。
- **图表自研**：`charts.js` 约 260 行，按容器实际宽度渲染（`Chart.mount`），窗口变化时防抖重绘，避免窄容器里字号被缩放得看不清。
- **表格组件** `DataTable`：排序、分页、每页条数、汇总行、空值渲染统一处理；年份列用 `plain: true` 避免"2,024"这种千分位。

### 2. 桌面端：一个 exe 干三件事

`zhinongbao.py` 按参数分派：

```bash
智农宝.exe                 # 首次运行询问安装；已安装则直接启动
智农宝.exe --install       # 安装（--silent 免确认）
智农宝.exe --uninstall     # 卸载（--silent 免确认）
智农宝.exe --no-browser    # 只起服务
智农宝.exe --port 9000     # 指定端口
智农宝.exe --idle 0        # 关闭空闲自动退出（默认 900 秒）
智农宝.exe --status        # 打印安装状态 JSON
```

几个实际踩过的坑，代码里都做了处理：

| 问题 | 处理 |
| --- | --- |
| Windows 允许两个进程同时绑同一端口（都设 `SO_REUSEADDR` 时），导致请求被分给旧版本服务 | 绑定前先主动连一次端口；被占用就换下一个，并用 `%LOCALAPPDATA%\ZhiNongBao\runtime.json` 记录真实端口 |
| 自定义端口时，下一次启动找不到已运行实例 | 运行状态文件记录端口，启动时先读它 |
| 安装流程被单实例互斥体拦掉（上一个实例刚退出时） | 安装/卸载在互斥体检查之前执行 |
| 卸载时 exe 正在运行，目录删不掉 | 写一个带重试的 `.cmd`，等进程退出后再删 |
| 中文快捷方式路径写进 PowerShell 脚本会乱码 | 脚本正文保持纯 ASCII，中文路径通过环境变量传给 `WScript.Shell` |
| 桌面被 OneDrive 重定向 | 用 `SHGetKnownFolderPath` 取真实桌面目录 |
| `urllib` 走系统代理，探测 127.0.0.1 要等 7 秒超时 | 改用 `http.client` 直连回环地址 |
| 用 `GetLastError()` 判断互斥体不可靠 | `ctypes.WinDLL('kernel32', use_last_error=True)` + `ctypes.get_last_error()` |
| 覆盖安装留下 `智农宝.old` | 安装成功后清理备份文件 |

### 3. 安全边界

- 服务只绑 `127.0.0.1`，不监听 `0.0.0.0`；
- 只读：没有任何写接口，唯一的 POST 是 `/__zn/shutdown`（本机优雅退出）；
- 路径穿越防护：静态文件解析后必须仍在 `site/` 目录内；
- 安装/卸载只写 `HKCU`（当前用户），不需要管理员权限，不碰系统目录。

## 三、改数据

面板字段（`dashboard.json → panel.rows[]`）必须包含：

```
省份, 大区, 年份, 总GDP(亿元), 人均GDP(元), 第一产业GDP(亿元),
第一产业占GDP比重(%), 常住人口(万人), 农村居民人均可支配收入(元),
农村居民人均第一产业收入估算(元)
```

`大区` 取值必须是 `东部 / 中部 / 西部 / 东北` 之一（用于筛选与区域工作台）。
指标定义在 `site/assets/js/app.js` 顶部的 `METRICS` 数组里，改标签、单位、聚合方式（`sum / ratio / perCapita / mean`）都在这儿。

改完依次执行：

```bash
python tools/build_core_data.py     # 重建 core-data.js
python tools/build_exe.py           # 需要重新分发时再打包
```

## 四、改界面

- 颜色、圆角、字号：`site/assets/css/style.css` 顶部 `:root` 变量；
- 侧边栏导航项：`index.html` 里的 `<nav>`，同时要加 `TITLES` 里的标题映射与 `ROUTES` 里的处理函数；
- 新增页面三步：写页面函数 → 注册到 `ROUTES` → 加 `TITLES` 与侧边栏 `<a>`。

## 五、验收

```bash
# 起一个测试实例
python desktop/zhinongbao.py --no-browser --port 8899

# 另开一个终端
ZN_BASE=http://127.0.0.1:8899 node tools/smoke_test.mjs
```

输出 `outputs/qa/smoke_result.json`：每个路由的标题、字数、控制台错误数，以及 21 项交互断言结果；同时生成桌面/移动端截图。
